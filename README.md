# HotTake

A decoupled full-stack social feed platform designed for real-time discussion, media sharing, and community engagement.

## Architecture

* **Backend:** ASP.NET Core Web API, Entity Framework Core, PostgreSQL, JWT Authentication
* **Frontend:** React, TypeScript, TanStack Query, Zustand, Tailwind CSS
* **Infrastructure:** Docker, Docker Compose
